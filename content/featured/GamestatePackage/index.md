An open-source Python package that enables coaches, analysts, and researchers to analyze any segment or instance of football match data without writing lengthy preparation scripts. Supports game state, possession context, tactical phase, and time filters — allowing questions like "How does Team X build up from the defensive third when losing?" to be answered and visualized instantly.
